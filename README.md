# ♟️ Chess – You vs. AI (Python + Pygame)

A fully functional chess game built with Python and Pygame, featuring:

- All standard chess rules (castling, en passant, pawn promotion)
- A computer opponent using **Minimax with Alpha‑Beta pruning**
- Piece‑square tables for positional evaluation
- Clean, modular codebase – ideal for learning, expanding, or upgrading

---

## ✨ Features

- 🎮 **Play White against the AI (Black)** – configurable
- ♟️ **Full rule set** – castling, en passant, pawn promotion (auto‑queen)
- 🧠 **AI opponent** – depth‑2 minimax with move ordering for speed
- 🎨 **Custom piece images** – 128×128 PNGs in `assets/`
- 🧩 **Clean project structure** – separate modules for game logic, AI, UI, and config
- ⚡ **Optimised** – alpha‑beta pruning, piece‑square evaluation
